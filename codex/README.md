# 돈값하나 Codex 발행 경로

기존 Claude 큐 및 발행 스크립트와 독립적으로 동작합니다. 콘텐츠는 `codex/content.json`, 공개 미디어는 `codex/assets`, 승인·댓글·게시 ID·지표는 암호화된 `codex/state.enc`에 저장합니다.

## 운영 시간 (한국 시간)

- 게시: 월·수·토 20:00부터. GitHub Actions는 15분마다 확인하므로 정각 실행은 보장하지 않습니다. 22:00 이후에는 해당 예약을 자동 게시하지 않습니다.
- 최종 승인 요청: 전날 20:00부터 Telegram으로 실제 이미지, 영상, 음원, 양쪽 본문, 첫 댓글과 후속 답글을 보냅니다.
- 전날 소유자가 해당 버전의 예약 승인 버튼을 눌러야 게시합니다. 무응답·보류·수정 요청·다른 버전의 승인은 게시하지 않습니다.
- 오늘 보내는 사전 미리보기의 테스트 버튼은 게시 승인이 아닙니다.
- Telegram의 일반 텍스트 피드백은 미게시 콘텐츠를 보류하고 암호화해 기록합니다. 이 엔진 자체는 자유문 피드백을 읽고 원고를 다시 쓰는 LLM이 아닙니다. 수정된 콘텐츠는 재승인이 필요합니다.

## 콘텐츠와 댓글

첫 3편은 무료배송을 채우는 추가 구매, 할인 카운트다운, 정리함을 사기 전의 선택입니다. Codex 콘텐츠는 일상의 선택과 반전, 구체적인 경험 질문을 중심으로 제작합니다. 같은 주제·훅·문장을 기존 Claude 큐에서 가져오지 않습니다. Instagram은 시각적인 상황과 결말을, Threads는 별개의 대화와 반론을 구성합니다. 실제 시세를 주장하지 않는 가상 장바구니와 창작 상황을 명시하고, 경험을 지어내지 않습니다.

현재 릴스는 밝은 크림색·코럴색의 장바구니 및 상자 그림, 장면별 2.5~4초 길이와 미세한 확대 효과로 구성합니다. 첫 영상은 20.5초, 세 번째 영상은 21.5초입니다. 직접 합성한 112 BPM 리듬을 입히며 외부 음원이나 샘플을 사용하지 않습니다. 캐러셀은 코발트색 타이머 화면을 포함한 정지 이미지이며 음원이 없습니다. 음악 플랫폼의 인기 음원을 자동으로 가져오는 기능은 없습니다.

이 제작 방향은 선택에 따른 소비 결과와 대화 반응을 보기 위한 첫 가설입니다. 신선함이나 도달을 보장할 수는 없으며 게시 후 저장·공유·의미 있는 댓글과 조회 지표를 보고 다음 훅과 길이를 조정합니다. 훈계형 마무리, 같은 교훈의 반복, 가짜 체험담, 확인하지 않은 제품 효과는 피합니다.

승인받은 Instagram 첫 댓글과 Threads 후속 답글은 본문 게시 후 자동 발행합니다. 방문자 댓글은 게시 후 7일 동안 시간당 조회하며, 한 번에 첫 50개까지 처리합니다. FAQ에 한 가지로 매칭되면 답글 후보를 Telegram으로 보내고 별도 승인을 받은 뒤 게시합니다. 나머지는 원문만 전달합니다. 임의의 타인 게시물에 홍보 댓글을 달지 않습니다.

게시 후 조회·도달·저장·공유 등 플랫폼에서 제공하는 지표를 수집합니다. 권한 부족·미지원 지표는 0이 아니라 조회 불가로 남깁니다. Claude의 기존 발행 기록과 Codex 발행 기록을 읽어 게시 후 24~27시간 사이의 지표를 한 번 저장하고, 일요일 19시 이후 최근 수집분을 Telegram으로 보고합니다. 작성 주체·플랫폼·릴스/피드별 표본 수와 평균을 분리합니다. 관측 시간을 놓친 오래된 게시물은 비교에서 제외합니다. 주제와 요일이 달라 엄밀한 인과 실험은 아닙니다. 모든 방문자 댓글을 이해하는 AI 답변은 아직 구현하지 않았습니다. 해시태그만으로 도달을 보장하지 않습니다.

## 검증과 장애 처리

`python -m unittest discover -s codex/tests -v`로 승인 날짜, 테스트 승인 차단, 버전 결속, 소유자 확인, 중복 실행, 저장 실패 시 발행 차단을 검사합니다.

각 외부 게시 호출 전에 암호화된 실행 기록을 먼저 원격 저장합니다. 호출 후 결과가 불명확하면 자동 재시도를 막고 Telegram에 알립니다. 해당 계정의 실제 게시 여부를 확인한 뒤 복구해야 합니다. 실제 Meta 발행 및 방문자 댓글 권한은 첫 승인 게시가 성공하기 전까지 검증 완료로 볼 수 없습니다.

GitHub Secrets의 기존 IG/TH 토큰과 `TELEGRAM_BOT_TOKEN`, 기존 `content/telegram_owner.enc`를 사용합니다. 토큰을 코드나 실행 로그에 출력하지 않습니다. 기존 봇 webhook이 있으면 충돌을 피하기 위해 중단합니다.
