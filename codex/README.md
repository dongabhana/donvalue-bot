# 돈값하나 · GPT 콘텐츠 운영

GPT 원고는 `codex/content.json`, 50편 편집 목록은 `codex/editorial-bank.json`에 있습니다. Claude 원고는 기존 `content/queue.yaml`을 사용합니다. 두 발행 경로는 같은 Meta 계정과 Telegram 봇을 사용하며 GitHub Actions에서 실행됩니다. 게시 경로는 Claude/OpenAI 생성 API를 호출하지 않아 대화 크레딧 소진만으로 준비된 게시가 중단되지는 않습니다.

## 원고와 일정

9월 12일 추가 요청으로 쿠폰 최소금액·노트북 추가비용·로봇청소기 준비 3편은 같은 날 Instagram·Threads 모두 6장 카드뉴스로 예외 발행합니다. 기존 Claude 4편이 끝난 뒤 발행 기록 기준 40분 간격으로 실행합니다. `seed-three.json`의 항목 ID·원고 해시·날짜에만 예외를 묶으며, 완료 기록은 원래 정기 슬롯의 중복 발행을 막습니다.

다음 정기 게시인 9월 14일은 택시·대리 비교입니다. 서울 중형택시 공식 요금과 같은 시각·경로의 실제 대리 견적을 대조하는 확인 항목을 제시합니다. 임의 귀가 총액을 넣거나 실제 대리 앱 견적을 조회했다고 주장하지 않습니다. 나머지 미발행 원고를 앞으로 당겨 월·수·토 슬롯을 채웠습니다. 현재 일정은 `content.json`이 기준이며 `editorial-bank.json`과 `콘텐츠_50편.md`는 최초 50편 원고 목록입니다.

- 새 원고 50편: IT 7, 결제 7, 구독·생활용품·가전·외식·이동·취미 각각 6편.
- 완결된 Threads 본문, Instagram 캡션·첫 댓글, 6장 카드·릴스 구성을 모두 포함합니다.
- 9월 14일 월요일부터 2027년 1월 6일 수요일까지 월·수·토 20시(KST)에 배치했습니다. 수요일은 캐러셀, 월요일·토요일은 릴스입니다.
- 카테고리는 번갈아 배치하며, 기존 무료배송 글은 9월 12일 게시 완료 기록을 유지합니다.
- 숫자와 계약·구매 조건은 명시된 가상 예시입니다. 실제 업체 가격·정책·효과를 확인한 것처럼 표현하지 않습니다. 실제 상품 비교를 넣을 때는 게시 전 공식 자료와 날짜를 확인해야 합니다.
- `콘텐츠_50편.md`는 최초 가상 예시 원고 보관본입니다. 개편한 예정 원고는 `content.json`과 `가격검증_기준.md`에서 읽을 수 있습니다.

## Threads 구성

새 원고는 훅, 상황·계산, 실행 방법, 경험 질문과 조건을 하나의 500자 이하 본문에 담습니다. 보충 내용을 읽기 위해 자기 답글 타래를 따라가야 하는 구성은 사용하지 않습니다. `threads_chain`은 새 50편에서 비어 있습니다. `threads_tag`를 API의 실제 `topic_tag` 필드로 전달합니다.

## 디자인과 릴스

쿠폰·노트북·로봇청소기 3편과 택시·대리 비교 편의 첫 화면은 생성형 사진에 큰 두 줄 훅을 얹습니다. 사진은 가상 연출이며 실제 제품 시험이나 구매 증거가 아닙니다. 본문은 계산·조건·실행 방법을 담는 기존 6장 구성을 유지합니다. 사진 파일 해시를 원고에 묶고 렌더링 시 검사하여 파일이 달라지면 새 버전 준비와 검수가 필요합니다. 생성형 사진은 사전 제작한 자산이며 예약 실행이 새 사진을 자동 생성하지는 않습니다.

`money_editorial_v2` 렌더러는 큰 두 줄 훅, 핵심 숫자, 카테고리별 색상, 직접 그린 간결한 아이콘, 계산 패널을 사용합니다. 단어를 중간에 끊지 않도록 줄을 나누고 안전 영역을 넘는 글은 렌더링을 중단합니다. 캐러셀은 1080×1350, 릴스는 1080×1920입니다.

첫 화면은 1.8초이며 별도 로고 인트로 없이 핵심 문장부터 시작합니다. 전체 영상은 18.6초, 장면별 컷과 짧은 확대·축소 움직임으로 구성합니다. 직접 합성한 112 BPM 리듬을 사용하며 음성 내레이션이나 플랫폼 인기 음원을 자동으로 가져오지는 않습니다.

## 승인과 게시

GPT는 약 15분마다 승인·예약 상태를 확인합니다. 이 주기는 게시 횟수를 뜻하지 않습니다. 실제 정각 실행은 GitHub 지연에 영향을 받습니다.

게시 전날 20시 이후 실제 이미지·영상·본문·음원 정보를 Telegram으로 보내고 소유자의 해당 버전 승인을 저장합니다. 전날 승인한 버전만 게시일 20~22시에 게시합니다. 수정 의견·보류·다른 버전 승인·무응답은 게시하지 않습니다. 사전 테스트 확인 버튼은 SNS 게시 승인이 아닙니다.

Claude 정기 일정은 화·목·일 20시입니다. 정기 실행의 기존 Telegram 승인 조건은 유지합니다. 9월 12일 사용자 요청의 카드뉴스 4편 연속 발행만 승인 없이 실행하며, 해당 복구 경로는 날짜와 항목 ID 4개에 한정합니다.

## 발행 기록과 장애 처리

GPT 상태는 `codex/state.enc`, Claude 시도 기록은 `content/delivery.json`, Claude 게시 이력은 `content/posted.json`에 남습니다. 외부 게시 전 시도 기록을 원격 저장하고, 성공 후 게시 ID를 저장합니다. 결과가 불명확한 시도는 자동 재게시하지 않고 실제 게시 여부를 먼저 확인합니다.

두 경로는 원격 변경을 rebase하고 push를 재시도합니다. 같은 파일이 충돌하면 강제로 한쪽을 선택하거나 발행 기록을 덮어쓰지 않고 중단합니다. GPT는 의미 있는 변경이 없는 상태를 재암호화·반복 커밋하지 않습니다.

## 반응 확인

게시 24~27시간 시점의 제공 가능한 조회·도달·저장·공유 지표를 수집합니다. 주간 보고에서 작성 주체·플랫폼·형식을 구분하고, 자료가 충분한 게시물은 저장·공유 대비 도달 비율과 카테고리·소재도 함께 확인합니다. 조회 실패는 0으로 바꾸지 않습니다. 이 데이터만으로 팔로워 증가의 원인이나 승자를 확정하지 않습니다.

방문자 댓글은 읽기 권한이 있을 때 확인합니다. FAQ에 유일하게 맞는 답글 후보는 별도 승인 후 게시하며 자유문 의견을 새 원고로 바꾸는 LLM은 이 실행 경로에 포함되어 있지 않습니다.

## 2026-09-12 예정 원고 전면 개편

정규 예정 48편을 조건별 선택·직접 확인·독립 질문으로 다시 작성했습니다. 공식 가격 비교 11편은 상품명·기준일·URL·계산 조건을 포함하며, 확인하지 못한 금액이 있는 나머지 37편은 임의 가격 없이 실제 조건을 대조하는 체크리스트입니다. `가격검증_기준.md`에 전체 원고와 기준을 기록했습니다.

새 사진 배경 12개와 기존 배경 4개를 소재에 맞게 사용합니다. 제품 실사 증거가 아닌 AI 연출 이미지임을 표지에 표시하고 원본 해시를 고정합니다. 릴스는 카드 이미지를 붙이는 대신 1080×1920 전용 화면으로 비교 근거를 순서대로 보여줍니다. 새 렌더러는 개편한 정규 원고에만 적용하며 당일 승인 3편은 변경하지 않습니다.

공식 가격은 `official_prices.py`가 미리보기와 발행 전 동일 출처의 지정 구간에서 다시 확인합니다. 표시 변경·조회 실패·다른 국가 구간·스크립트 안의 가격은 승인 근거로 쓰지 않으며 자동 발행을 멈춥니다. 기존 전날 Telegram 승인·원고/미디어 해시·중복 방지는 유지합니다.
