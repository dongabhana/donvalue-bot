# 「0년」 컷툰 폴더

인스타(@dongabhana → 「0년」 계정)에 월·수·금 21:20 자동으로 올라가는 컷툰이다.
한 화의 그림 15장을 이어 붙여 세로 릴스 영상(약 48초, 배경음·효과음 포함)으로 만든 뒤 게시한다.
인스타 공식 게시 API 는 캐러셀을 10장까지만 받아서 릴스로 올린다.

## 새 화 올리는 법

1. `toon/ep02` 처럼 폴더를 만든다(두 자리 번호).
2. GPT 가 그린 그림을 `01.png` ~ `15.png` 이름으로 넣는다. jpg·webp 도 된다.
3. `caption.txt` 에 인스타 캡션을 넣는다.
4. (선택) `timing.yaml` 에 장별 초 수와 효과음(`click`, `shutter`)을 적는다. 없으면 장마다 3초.

GitHub 웹에서 하려면 저장소 → `toon` 폴더 → Add file → Upload files 로 그림을 끌어다 놓고,
맨 위 파일 이름 칸에 `toon/ep02/` 를 붙이면 폴더가 생긴다.

## 미리 보기

Actions → 「0년 컷툰 릴스」 → Run workflow 에서 `dry_run` 을 켠 채 실행하면 게시하지 않고
영상만 만든다. 실행 결과 화면 아래 Artifacts 에서 mp4 를 받아 볼 수 있다.

## 규칙

- 다음 화 = `posted.json` 에 없는 가장 앞 번호 폴더. 그림이 없으면 텔레그램으로 알리고 그날은 쉰다.
- 하루 한 화. 이미 올린 화(`posted.json`)는 내용을 고치지 않는다.
- 캡션 2,200자, 해시태그 30개 이하. 장 번호가 없거나 겹치는 파일 이름은 멈춘다.
