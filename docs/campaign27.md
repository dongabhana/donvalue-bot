# 돈값하나 27편 세로 콘텐츠 제작 세트

기존 추천 발행 순서대로 27편을 각각 표지 1장, 본문 4장, 결론 1장,
인스타 CTA 1장, 유튜브 CTA 1장으로 제작합니다. 공통 6장에 해당 플랫폼
CTA 하나만 붙이므로 플랫폼별 영상은 7개 장면입니다. 27장의 포스터가 아닙니다.

## 원본과 재현

- `build/campaign27.json`(미리보기 산출물, 저장소에 두지 않음): 장면 원고, 전체 나레이션, 플랫폼별 CTA, 인스타 캡션,
  유튜브 제목·설명, 500자 이하 스레드, 계산 조건과 출처.
- `codex/campaign27.py`: 편집 가능한 콘텐츠 빌더. 기존 세로 렌더용 `cards`, `reel`,
  `reel_cards`와 게시문 필드를 함께 제공합니다.
- `tools/build_campaign27.py`: 기존 `src/theme.py` 디자인과 한글 폰트를 사용하는
  제작 렌더러. 1080×1920 PNG, 여성 한국어 장면별 음성, 플랫폼별 H.264/AAC MP4.
  본문을 길이 때문에 제거하지 않으며 음성 실패를 무음 성공으로 처리하지 않습니다.
- `assets/covers/p*.editorial-v3.jpg`: 주제를 표현하도록 새로 생성한 무문자 표지 사진.
  나머지 사진은 원본 JSON에 명시한 기존 저장소 사진을 재사용합니다.

```sh
pip install -r requirements.txt imageio-ffmpeg
python -m codex.campaign27
python tools/build_campaign27.py --out build/campaign27 --video
python -m unittest discover -s codex/tests -q
```

음성 합성은 기존 프로젝트와 같은 Edge TTS 서비스 네트워크 접근이 필요합니다.
출력 폴더의 `index.html`에서 장면과 영상을 함께 볼 수 있습니다. `--only 1 2`로
편을 선택할 수 있습니다. 콘텐츠를 고친 뒤 기존 MP3/MP4를 그대로 재사용하지 않도록
렌더러의 입력 해시로 캐시를 검증합니다.

## 숫자 편집 기준

실제 상품의 최신 판매가를 확인하지 않은 숫자는 가정값으로 표시했습니다.
AI·유튜브 월 요금은 계산 예시이며 현재 요금표나 성능 순위를 주장하지 않습니다.
시간가치는 통장에 들어오는 현금과 구분했습니다. 주요 교정은 다음과 같습니다.

- AI 29,000원/시간값 15,000원/22일은 하루 약 **5분 16초**.
- 텀블러 30,000원/400원은 **75회에 같아지고 76회부터 초과**.
- 야식 주 1회 감소의 130만원은 주문액 감소. 대체식 5천원을 넣으면 순절약 104만원.
- 로또 13만원은 전체 지급률에 기반한 세전 손실 기대값. 개인의 확정 손실이 아님.
- K-패스 20%→50%는 일반 정률 비교. 정액형·지역 혜택이 적용되면 추가 실익이 다름.
  연말 연장은 2026-09-28 보도를 대조했고 공식 사이트 이용자별 계산 확인이 필요합니다.
- 자동차 감가는 경제적 비용으로 현금 지출과 분리했습니다.

## 운영 연결 (2026-09-29 최종본)

- **오늘부터 발행**: `src/run.py` 가 슬롯마다 `src/campaign.py` 를 먼저 본다. 발행 기록에 없고
  표지가 준비된 편을 **번호 순서대로** 하루 1편 낸다(인스타 릴스 → 유튜브 쇼츠 → 쓰레드).
  캠페인에 낼 편이 없을 때만 기존 큐(`content/queue.yaml`)로 넘어간다.
- 큐의 d001~d007은 캠페인 p11·p05·p23·p26·p25·p24·p27과 주제가 같아 `hold: true`(보관).
- **표지 대기 12편**(1·3·4·7·9·10·12·15·17·20·22·25편): 관련 사물만 보이는 재사용 사진이라
  반려. `assets/covers/<id>.editorial-v3.jpg`(예: `p12-rental.editorial-v3.jpg`) 새 파일이
  들어오면 원고를 다시 만들지 않아도 다음 슬롯부터 발행 대상이 된다. p04·p20 은 지금 파일(SHA-256)이
  반려돼 다른 파일로 바꿔야 풀린다. 표지 기준: **글자를 전부 가려도 그 편의 상황·비교가 드러나는가.**
- 매 발행마다 편 폴더를 비우고 새로 렌더한다(이전 음성·영상 캐시 없음). 영상 길이가 장면 합계와
  1초 넘게 다르거나 평균 음량이 -40dB 아래(무음)면 발행하지 않는다(`verify.json`).
- 유튜브: 표지 JPEG 로 `thumbnails.set` 을 시도한다. 쇼츠 맞춤 썸네일은 2026-07-24부터
  파트너 프로그램 채널부터 열려 거절될 수 있다 → 실패해도 발행은 유지하고 로그·텔레그램에 남긴다.
  영상 첫 장면이 표지이고 표지 장면을 훅 나레이션 동안 보여 준다.
- 미리보기 ZIP: Actions → **27편 제작본 미리보기(ZIP)** 실행(원고·렌더러·표지가 main 에 바뀌면 자동).
  발행본과 같은 코드·원고에서 만든다.

## 편집 규칙

- 원고 원본은 `codex/campaign27.py` 하나다. 발행·렌더가 이 파일을 직접 읽는다(JSON 사본 없음 →
  원고와 사본이 어긋날 수 없다). 검토용 JSON 은 `python -m codex.campaign27 build/campaign27.json`.
- 나레이션(`EXTRA[..]['narr']`)은 화면 글자를 읽지 않고 설명하듯 쓴다. 기호(~ % × →)를 쓰지 않는다.
- 해시태그: 주제 3개(인스타 게시물 수 수천~100만) + 공통 2개(#생활꿀팁 #돈모으기) = 5개.
- 나레이션 속도 +22%(ko-KR-SunHiNeural), 배경음은 자체 합성으로 말 아래 -22dB + 더킹.
