# 돈값하나 본문·엔딩 디자인 v3

본문·비교·결론·마지막 화면을 같은 짙은 청록 바탕으로 통일한다. 표지 렌더는 유지한다.

- 비교: 두 값을 별도 패널에 배치하고 실제 값에 비례한 막대로 차이를 보여준다.
- 계산: 핵심 결과와 비용 항목을 분리한다. 원고의 숫자와 문장은 임의로 줄이지 않는다.
- 기준: 세 번째 본문에서 큰 숫자를 독립시켜 앞 장면과 구도를 바꾼다.
- 체크: 조건을 체크 목록으로 보여준다. 세 항목보다 많으면 원문 전체를 표시한다.
- 결론: 점수보다 결론 문장을 우선한다.
- 마지막: 계정 소개, 좋아요+팔로우/구독 버튼, 해당 편의 질문을 구분한다.

공유 그래픽은 `src/editorial_design.py`에 있으며 실제 캠페인 제작기와 일반 큐 장면 제작기가 함께 사용한다. 출력은 캠페인 1080×1920, 일반 큐 1458×2592 규약을 유지한다. 숫자는 라임, 행동 버튼은 코럴, 보조 설명은 회청색이다. 핵심 문구는 x=60~958, y=120~1600 안에서 검사한다.

캠페인 본문·결론·엔딩에 0.18초 진입 효과를 넣는다. 표지는 즉시 보이고 기존 나레이션 길이와 장면 수는 유지한다. 인코딩 캐시 키에 디자인 버전을 포함해 예전 영상이 재사용되지 않게 한다. 일반 큐는 기존 모션 처리를 유지한다.

검증은 `python -m unittest discover -s codex/tests -q`로 실행한다. Windows에서는 `CODEX_FONT`에 사용 가능한 한글 폰트를 지정한다. 새 회귀 테스트는 27편의 본문·결론·두 플랫폼 엔딩 189장을 실제 렌더하며, 긴 문구 초과와 플랫폼별 CTA를 검사한다.

발행 기록·이미 올라간 영상·발행 일정·승인 흐름·콘텐츠 원고는 변경하지 않는다. 검토용 영상은 기존 보관 음성으로 만들 수 있으며, 이 경우 미리보기 장면 목록에 실제 사용한 대본을 적는다. 시청 유지율 개선 여부는 게시 후 데이터로 확인한다.
