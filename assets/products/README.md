# 추천템 제품 사진

`codex/campaign_first10.py` 의 `PHOTOS` 에 적힌 파일 이름으로 있으면, 그 편의 '실제 후보' 장면이
사진 장면으로 바뀐다. 파일이 없으면 기존 글자 장면 그대로 발행된다.

- 2026-10-15 소유자 결정: 다이소몰 상품 **대표 이미지**를 쓴다. 화면(품번 줄)과 캡션에 '다이소몰' 출처를 적는다.
- 고객 리뷰 사진은 각 작성자의 것이라 쓰지 않는다. AI 이미지는 실제 물건과 달라 쓰지 않는다.
- 받는 방법: GitHub Actions → '추천템 제품 사진 받기'(product-photos.yml) 수동 실행.
  Claude 작업 환경에서는 다이소몰 CDN 이 막혀 있다.
- 직접 찍은 사진으로 바꾸려면 같은 파일 이름으로 덮어쓰면 된다(가운데 기준 약 7:5 가로로 잘림).
- 이미 발행된 편(content/posted.json)은 사진을 바꿔도 다시 올라가지 않는다.
