# 클로드·제작 도구 인계

## 파일

- index.html: 표지·원고 검토 갤러리. 인터넷 없이 열립니다.
- content.json: 10편 원고, scenes(장면), caption_instagram, description_youtube, threads_text, sources, cover.
- scripts.md: 사람이 읽는 전체 원고.
- scripts/01.txt … 10.txt: TTS에 넣을 나레이션만. 제작 메모를 음성으로 읽지 않습니다.
- covers/01.png … 10.png: 내장 이미지 생성 도구로 만든 세로 표지 원본.
- cover-prompts.json: 최종 표지 생성 프롬프트.

## 연결 방식

이 JSON은 독립 인계 형식입니다. 기존 donvalue-bot에 바로 덮어쓰는 큐가 아닙니다. 기존 queue.yaml/campaign 데이터에 옮길 때 각 필드를 변환하고 회귀 검사를 거쳐야 합니다.

- id는 이번 패키지 내부 번호이며 기존 발행 ID와 다릅니다. 이관 시 고유한 ID를 붙입니다.
- 발행 순서는 01~10, 날짜는 미지정입니다. 기존 예약과 겹치지 않는 슬롯에 배치합니다.
- auto_publish=false, publish_at=null, status=ready_for_editorial_review로 두었습니다. 이 패키지를 읽었다는 이유만으로 외부 발행을 하지 않습니다.
- hook은 첫 음성, beats는 본문 장면입니다. scenes에 완성 나레이션이 나뉘어 있으므로 narration을 중복 삽입하지 않습니다.
- cover.file은 이 폴더 기준 상대 경로입니다. 해당 파일을 제작 저장소로 복사 후 경로를 바꿉니다.
- 실제 TTS 오디오 길이를 기준으로 scenes의 시각을 재계산합니다. 현재 시간은 추정이며 완성 자막 파일이 아닙니다.
- 표지의 생성 장면은 제품 실물·실제 거래·실험 성능 증거가 아닙니다. 01·07 캡션의 연출 고지를 유지합니다. 실제 상품 외형을 설명할 때는 공식 제품 자료 확인 또는 직접 촬영 자료를 사용합니다.
- 02는 할인 보장/수령 후기가 아닙니다. 03은 실제 매입 견적이 아닙니다. 04·05·06·08·09의 수치는 명시적 예시입니다.
- 01·07은 제품명·품번·가격 확인일을 유지하고 게시 직전 최신 상태를 다시 확인합니다.
- 유튜브는 구독, 인스타는 팔로우 문구로 구분합니다. 플랫폼별 기능/가격/성능에 대한 새 주장은 출처 확인 후 추가합니다.

## 편집 메모

첫 문장부터 상황이 들어옵니다. 동일한 PPT 상자 네 장을 반복하지 말고 사물 클로즈업·선택지·짧은 숫자 비교를 섞습니다. 화면 자막과 나레이션은 완전히 같은 긴 문장을 중복하지 않습니다. 마지막에는 해당 주제의 질문을 남깁니다.

아직 제작하지 않은 것: 본문 영상·나레이션 음성·실제 실험 촬영. 완성한 것: 표지 10장·대본 10편·장면 구성·플랫폼별 게시 문안·출처·연결용 데이터.
